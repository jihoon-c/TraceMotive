# TraceMotive — Unreal 디버그 패스파인더

[English](README.md) | 한국어

TraceMotive — Unreal 디버그 패스파인더는 Blueprint와 레벨 인스턴스의 관계를
분석하는 Unreal Engine 에디터 전용 플러그인입니다. 패키징된 게임에는 런타임
코드를 추가하지 않습니다.

## 개요

TraceMotive는 디버깅 질문에서 답을 확인할 수 있는 에디터 객체, Blueprint 노드,
런타임 인스턴스 또는 충돌 설정까지 찾아가는 과정을 단축합니다. Fab v1에서는
고객에게 제공하는 기능을 다음 네 가지 핵심 도구로 제한합니다.

- Blueprint 심볼을 참조하는 노드를 찾아 이동
- 선택한 에셋이 실제로 사용되는 위치 확인
- PIE 인스턴스에서 선택한 프로퍼티 값 관찰
- 두 액터가 서로 충돌하거나 통과하는 이유 분석

각 도구는 확인된 근거와 분석 한계를 구분해 표시합니다. 검증된 객체 참조를
텍스트 후보와 섞지 않으며, 샘플링된 값을 완전한 쓰기 이력으로 표현하지 않고,
충돌 가능한 설정을 실제 게임 이동 경로의 충돌 증명으로 표현하지 않습니다.

## Fab v1 활성 기능

**TraceMotiveTools → 핵심 도구 / 여기서 시작**에서 다음 네 도구를 사용할 수 있습니다.

### 시각 참조 검색

Blueprint 그래프에서 변수, 함수, 이벤트 또는 디스패처를 우클릭해 컨텍스트 검색을
시작합니다. 결과에는 Blueprint, 그래프 및 노드 식별 정보가 유지되므로 정확한 원본
노드로 이동할 수 있습니다. 중첩 그래프를 포함하며, 서로 다른 패키지에 있는 동명
에셋을 별개의 대상으로 유지합니다.

“이 값은 어디에서 읽거나 쓰는가?”, “어떤 Blueprint 경로가 이 함수를 호출하는가?”와
같은 질문을 조사할 때 사용합니다. 결과는 정적 에디터 근거입니다. 동적으로 구성된
호출이나 현재 엔진 빌드가 제공하지 않는 런타임 컨텍스트는 확인되지 않을 수 있습니다.

### 에셋 사용 위치

콘텐츠 브라우저에서 에셋을 선택한 다음 **에셋 사용 위치**를 엽니다. 결과 화면은
검증된 객체 참조와 추가 확인이 필요한 Asset Registry 또는 텍스트 후보를 구분합니다.
Blueprint 핀, 클래스 기본 객체, 컴포넌트 템플릿, 프로퍼티 및 지원되는 소프트 참조
근거를 검사합니다.

진행 상태, 로딩 실패, 취소 및 결과 잘림 여부를 명시적으로 표시합니다. 스캔을
취소하면 이미 수집된 근거를 유지하며, 부분 결과를 전체 결과로 잘못 표시하지 않습니다.

### 변수 값 추적

PIE 실행 중 클래스와 관찰할 프로퍼티를 하나 이상 선택합니다. 인스턴스는 월드와
전체 객체 경로로 구분되므로 여러 월드에서 이름이 같은 객체도 식별할 수 있습니다.
0.05초, 0.1초, 0.5초 샘플링 간격을 제공하며 특정 인스턴스로 표시 결과를 필터링할
수 있습니다.

이 기능은 샘플링 기반 상태 관찰 도구이며 쓰기 이벤트 훅이 아닙니다. 샘플 사이에서
값이 바뀌었다가 원래 값으로 돌아오면 기록되지 않을 수 있습니다. 재귀 구조나 매우 큰
값에는 처리 예산을 적용하고, 생략된 값은 빈 값으로 처리하지 않고 상태에 표시합니다.

### 충돌 쌍 분석

두 액터를 선택하고 분석기를 실행해 두 액터의 프리미티브 컴포넌트 조합을 검사합니다.
충돌 활성화 상태, 채널 응답, 오버랩·접촉 근거 및 짧은 Sweep 탐색 근거를 구분합니다.
또한 `Sweep=false`, 텔레포트 방식 이동, 충돌하지 않는 Updated Component와 같은
일반적인 이동 경로 위험을 안내합니다.

분석은 여러 프레임에 나누어 실행되며 취소할 수 있습니다. “Block 가능”은 검사한
설정이 차단을 허용한다는 의미입니다. 실제 게임 결과는 이동 API, 무시 목록, 물리
상태 및 실제로 이동하는 컴포넌트에 따라 달라집니다.

## 성능 및 대규모 프로젝트 대응

TraceMotive는 절대적인 프레임 시간 상한을 보장하지 않으면서 에디터 진단의 응답성을
유지하도록 설계되었습니다. 현재 구현에는 다음 보호 기법이 적용되어 있습니다.

- **틱 단위 분할 처리:** 참조, 에셋 사용 위치 및 충돌 스캔을 제한된 작업 단위로
  나누어 여러 에디터 틱에서 처리합니다.
- **재개 가능한 커서:** 긴 Blueprint 및 패키지 스캔은 그래프·노드 또는 후보 위치를
  저장하고 다음 틱에 해당 위치부터 계속합니다.
- **제한된 비동기 로딩:** 로드되지 않은 Blueprint와 에셋 후보를 한 번에 모두 읽지
  않고 동시 처리 수를 제한해 비동기로 요청합니다.
- **대규모 프로젝트 안전 모드:** 기본값으로 활성화되며 보수적인 스캔 예산을 사용하고,
  선택적 검색 가속이 예상보다 많은 작업을 발생시키지 않도록 제한합니다.
- **명시적인 데이터 한도:** 참조 및 에셋 사용 위치 결과에는 제한 범위가 보장된 상한을
  적용하고, 재귀 런타임 값 내보내기에는 고정된 순회 예산을 적용합니다. 한도 도달은
  부분 결과, 잘린 결과 또는 생략된 값으로 표시됩니다.
- **UI 갱신 제한:** 항목을 하나 찾을 때마다 전체 UI를 다시 만들지 않도록 진행 상태와
  결과 위젯을 제한된 주기로 갱신합니다.
- **협력적 취소:** 실행 중인 작업이 취소 세대를 기록하므로 도구를 취소하면 대기 중인
  작업도 안전하게 무효화됩니다.
- **프로파일링 지점:** 주요 검색, 샘플링 및 충돌 경로에 Unreal Insights CPU 스코프를
  제공하여 실제 프로젝트에서 측정할 수 있습니다.

이 기법들은 에디터를 장시간 연속 점유하는 작업을 줄이지만, 단일 패키지 로드, 매우 큰
프로퍼티 검사 또는 한 번의 물리 쿼리 같은 개별 엔진 연산은 명목상 틱 예산을 초과할 수
있습니다. 성능 수치를 제시하기 전 대표 프로젝트에서 콜드·웜 실행을 각각 측정하십시오.

등록되지 않습니다.

## 출시 기능 범위

Fab v1 빌드는 위의 핵심 도구 네 가지만 노출합니다. 그 밖의 실험 기능과 향후
업데이트용 기능은 소스 트리에 컴파일 가능한 상태로 남아 있지만, 에디터 메뉴,
컨텍스트 액션 또는 탭을 등록하지 않습니다. 이를 통해 구현을 버리지 않으면서 검수가
끝나지 않은 기능을 고객 워크플로에서 제외합니다.

## 설치

1. 플러그인을 프로젝트의 `Plugins/TraceMotive` 폴더에 배치하거나, Fab 등록 후
   Fab을 통해 설치합니다.
2. Unreal Editor 플러그인 브라우저에서
   **TraceMotive — Debug Pathfinder for Unreal**을 활성화합니다.
3. 안내가 표시되면 에디터를 다시 시작합니다.

플러그인 모듈 형식은 `Editor`입니다. 게임 또는 서버 타깃에서는 로드되지 않습니다.

## 엔진 호환성

- Unreal Engine 5.8.2 / Win64: 소스 컴파일 및 `BuildPlugin` 패키징 검증 완료
- 패키징 바이너리 빌드 ID: `55116800`

바이너리 패키지는 엔진 빌드에 종속됩니다. 다른 Unreal Engine 패치 버전이나 커스텀
엔진 빌드에서는 소스로부터 플러그인을 다시 빌드하십시오.

## 로컬 데이터 처리

플러그인은 프로젝트 데이터를 로컬에서 처리합니다. 네트워크, 분석 수집, 광고,
텔레메트리, 계정 또는 결제 코드를 포함하지 않습니다. 읽는 프로젝트 데이터와 생성할
수 있는 로컬 파일은 [PRIVACY.md](PRIVACY.md)를 참고하십시오.

활성 도구는 프로젝트 데이터를 업로드하지 않습니다. 보고서 또는 복사된 진단 텍스트는
사용자의 명시적인 동작으로만 생성되며 프로젝트 에셋, 액터, 클래스 또는 패키지 이름을
포함할 수 있습니다. 다른 사람과 공유하기 전에 내보낸 내용을 검토하십시오.

## 주요 제한 사항

- 추적 결과는 디버깅 근거이며 가능한 모든 런타임 호출자를 식별했다는 형식적 증명이
  아닙니다.
- Blueprint 호출자 식별은 현재 Unreal Engine 빌드가 제공하는 런타임 컨텍스트에
  의존하며, 확인되지 않은 상태로 표시될 수 있습니다.
- 틱 예산은 협력적으로 분할 가능한 스캔 루프를 제한하며 모든 개별 엔진 API 호출의
  실행 시간을 제한하지는 않습니다.
- 결과 상한, 로드 실패, 취소 및 재귀 값 제한으로 인해 의도적인 부분 결과가 생성될 수
  있으며, 도구는 이를 진행 상태 또는 요약 UI에 표시합니다.
- Fab에서 제공하는 각 엔진 버전에 대해 별도의 호환성 검증이 필요합니다.
