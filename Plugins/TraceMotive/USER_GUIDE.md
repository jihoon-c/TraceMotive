# TraceMotive v1 사용 안내

TraceMotive는 언리얼 에디터에서 블루프린트 참조, 에셋 사용 위치,
PIE 프로퍼티 값, 두 액터의 충돌 설정과 PIE 배속을 확인·제어하는 도구입니다.
게임 패키지에서 실행되는 런타임 모듈은 포함하지 않습니다.

## 설치와 시작

1. 프로젝트의 `Plugins/TraceMotive`에 플러그인을 넣습니다.
2. 에디터 플러그인 브라우저에서 TraceMotive를 활성화하고 재시작합니다.
3. Window 메뉴의 `TraceMotiveTools` 또는 Tools 메뉴의 TraceMotive에서
   `Core tools / Start here`의 다섯 도구를 엽니다.

검증한 환경은 UE 5.8.3, Windows 64비트입니다. 다른 엔진 빌드에서는
소스 재빌드가 필요할 수 있습니다.

## 블루프린트 참조 검색

1. BP 그래프에서 검색할 변수 GET/SET, 함수 호출·진입, 이벤트 또는
   디스패처 Call/Bind/Unbind/Assign 노드를 우클릭합니다.
2. `Visual Find References`, `Visual Find Function References` 또는
   `Visual Find Dispatcher References`를 선택합니다.
3. 검색 범위를 고르고 `Full scan`을 켠 상태로 검색합니다.
4. 결과의 BP·그래프·노드 정보와 참조 근거를 확인합니다.
   결과 항목을 더블클릭하면 원본 참조 위치로 이동합니다.

| 범위 | 검색 대상 |
|---|---|
| Current Blueprint | 검색 대상 BP의 그래프와 중첩 그래프 |
| Same Folder | 검색 대상 BP와 같은 콘텐츠 폴더의 BP; 하위 폴더 제외 |
| Project Content | `/Game`과 대상 BP 콘텐츠 마운트의 BP 전체 스캔 및 우선 참조 후보 |

`Full scan`을 끄면 빠른 후보 검색이 적용되어 참조가 누락될 수 있습니다.
로컬 변수는 해당 BP와 함수 범위 안에서만 일치하며, 동명 멤버 변수와
다른 함수의 로컬 변수는 결과에서 제외합니다.

기본 검색은 블루프린트만 검사합니다. 변수의 Project Content 검색에서
`Include C++ candidates`를 켜면 프로젝트 `Source`와 `Plugins`의
C++ 식별자 텍스트 후보도 표시됩니다. 이 옵션은 검색 시간을 늘릴 수
있으며 기본값은 꺼짐입니다. C++ 후보는 소유 클래스·타입을
수동으로 확인해야 하며, 설정된 결과 한도에 도달하면 일부만 표시됩니다.

결과는 저장된 그래프의 정적 참조 근거입니다. 문자열로 구성한 함수 이름,
런타임에 결정되는 호출 대상 등은 확정할 수 없습니다. 엔진 콘텐츠와
모든 외부 플러그인 콘텐츠를 빠짐없이 검색한다는 보장은 제공하지 않습니다.

## 에셋 사용 위치

콘텐츠 브라우저에서 에셋을 선택하고 `Asset Usage Locator`를 엽니다.
확인된 객체 참조와 추가 확인이 필요한 메타데이터·텍스트 후보를 구분해
읽습니다. 노드·핀·기본 프로퍼티 등의 근거에서 원본 위치를 확인합니다.
취소, 로딩 실패 또는 결과 잘림이 표시되면 전체 검색 결과로 해석하지 않습니다.

## 변수 값 관찰

PIE를 시작하고 `Variable Value Trace`에서 클래스와 관찰할 프로퍼티를
선택합니다. 월드와 전체 객체 경로로 인스턴스를 구분하고, 필요한 경우
특정 인스턴스로 필터링합니다. 샘플링 간격은 0.05, 0.1, 0.5초입니다.

샘플 사이에 값이 바뀌었다가 돌아오면 기록되지 않을 수 있습니다.
큰 컨테이너나 재귀 값은 제한될 수 있으므로 생략 안내를 확인합니다.
BP 재컴파일·클래스 교체로 관찰이 중단되면 대상을 다시 선택합니다.

## 충돌 쌍 분석

레벨에서 두 액터를 선택하고 `Collision Pair Analyzer`를 실행합니다.
컴포넌트 쌍의 Collision Enabled, 채널 응답과 Overlap/Hit 관련 설정,
지원되는 접촉·짧은 Sweep 근거를 확인합니다.

차단 가능한 설정이라는 결과만으로 실제 이동이 차단됨을 보장하지는
않습니다. 이동 API의 Sweep·Teleport 옵션, 이동하는 컴포넌트,
Ignore 목록과 물리 상태를 함께 확인합니다.

## 전역 배속 제어

PIE에서 `Global Speed Control`을 열어 시간 배율과 오디오 피치를 조정합니다.
Skip to Target은 선택한 로그·Blueprint 대상에 도달하면 1x를 복구하고 PIE를
일시정지합니다. 모든 작업 중지는 배속을 복구하고 Skip 감시를 해제합니다.
PIE 종료 시 초기화 옵션을 끄면 설정이 다음 PIE에도 유지될 수 있습니다.

## 결과가 예상과 다를 때

- BP를 컴파일·저장하고, 올바른 노드에서 검색했는지 확인합니다.
- 검색 범위를 확인하고 `Full scan`을 켠 상태로 다시 검색합니다.
- 결과 한도, 취소·생략 안내와 로딩 상태를 확인합니다.
- 대형 프로젝트에서는 안전 모드를 유지하고 작업 예산과 결과 한도를
  프로젝트 규모에 맞게 조정합니다. 개별 패키지 로드와 큰 프로퍼티 검사는
  한 번의 작업만으로도 명목 시간 예산을 초과할 수 있습니다.
