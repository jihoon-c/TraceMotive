# 핵심 기능 출시 검수

## 공통 사용 흐름

대상 선택 → 분석/관찰 실행 → 진행 및 결과 범위 확인 → 근거 확인 → 원래 위치 이동.
런처 상단에는 참조 검색, 에셋 사용 위치, 변수 관찰, 충돌 분석만 핵심 기능으로 표시한다.
고급 런타임 도구와 시나리오는 접힌 영역으로 제공한다.

## Fab v1 기능 노출 정책

출시 빌드는 `TRACEMOTIVE_CORE_ONLY_RELEASE=1`로 구성한다. 이 모드에서는
비주얼 참조 검색, 에셋 사용 위치, 변수 값 추적, 충돌 쌍 분석만 등록한다.
그 외 기능은 코드에 보존하지만 메뉴, 컨텍스트 액션, 탭 스포너를 등록하지 않는다.
후속 버전에서 검수가 끝나면 `TraceMotive.Build.cs`의 값을 `0`으로 변경하고
전체 기능 회귀 테스트를 수행한 뒤 다시 노출한다.

## 자동 검증과 수동 검수의 구분

자동 테스트 성공은 아래 실제 에디터 검수를 대체하지 않는다.
특히 실제 UI 클릭, 멀티 PIE, 대규모 프로젝트 프레임 시간은 직접 확인해야 한다.

| 기능 | 재현 사례 | 기대 결과 |
|---|---|---|
| 참조 검색 | 읽기/쓰기 노드, 중첩 그래프, 다른 BP의 동명 변수 | 예상 노드만 찾고 결과에서 해당 노드로 이동 |
| 참조 검색 | 다른 폴더에 같은 이름의 BP | 결과 에셋이 합쳐지지 않음 |
| 참조 검색 | 상속, 인터페이스, 매크로, 디스패처 | 지원되는 참조와 동적 호출의 미확인 범위 구분 |
| 에셋 위치 | 핀 기본 객체, 텍스트 후보, CDO/컴포넌트 속성, 소프트 참조 | 확인된 객체 참조와 확인이 필요한 후보 구분 |
| 에셋 위치 | 큰 BP, 취소, 재검색, 로딩 실패, 결과 한도 | 진행 상태가 맞고 일부 결과를 전체 결과로 표시하지 않음 |
| 변수 관찰 | 같은 이름을 가진 멀티 PIE 인스턴스 | 월드/경로/객체 ID로 이벤트가 분리됨 |
| 변수 관찰 | 생성·소멸, BP 재컴파일, 관찰 대상 변경 | 오래된 객체 접근 없이 새 기준값으로 관찰 |
| 변수 관찰 | 짧은 값 변화, 큰 중첩 컨테이너 | 샘플링 한계와 예산으로 생략된 값을 안내 |
| 충돌 분석 | Ignore/Overlap/Block, 충돌 비활성, Hit/Overlap 이벤트 | 설정 원인을 설명하고 이벤트 설정과 물리 차단을 구분 |
| 충돌 분석 | Sweep/Teleport, 물리 시뮬레이션 | 설정상 차단 가능과 실제 이동 증거를 구분 |
| 충돌 분석 | 컴포넌트 다수, 취소, 대상 소멸 | 분할 처리·진행률·취소 동작, 잘못된 완료 결과 없음 |

## 성능 확인

Unreal Insights에서 TraceMotive 검색·변수 샘플·충돌 분석 구간을 측정한다.
작은/중간/큰 프로젝트의 대상 수, 결과 수, 최대 틱 소요 시간을 함께 기록한다.
개별 노드/프로퍼티/물리 쿼리는 분할 불가능한 단위이므로 시간 예산은 절대 상한이 아니다.
정량 측정 전에는 성능 향상 비율을 광고하지 않는다.
